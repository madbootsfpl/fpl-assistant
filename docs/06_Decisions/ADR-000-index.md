# ADR Index

An index of all Architectural Decision Records in this project. **Add a row for each new ADR as it is
created, and keep the table in ascending order** — appending wherever the cursor happened to be is how it
drifted into `…069 068 067 089 122…070 066` and then stopped being maintained at all.

*Backfilled 2026-08-31 (Sprint 231): the index had stopped at **ADR-122** while 171 ADRs existed — 49 missing,
found while filing ADR-171. Re-sorted ascending at the same time, because appending 49 rows to a scrambled
table would have produced something still unusable. Every link is checked to resolve to a real file.*
