## Purpose

GitHub is an online home for a Git repository — a backup, a place to collaborate,
and a hub for issues and automation (GitHub Actions).

---

## Why We Use It

Planned in the Project Charter. It will give the project an off-machine backup, a
backlog via Issues, and later CI (linting/tests) via Actions — all listed in the
Roadmap's Phase 1 "Environment & CI/CD".
