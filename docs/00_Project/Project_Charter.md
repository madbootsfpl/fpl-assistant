# Project Charter

**Project Name:** FPL Assistant *(Working Title)*

**Version:** 1.0

**Created:** July 2026

**Owner:** Tony Sheridan

**Technical Lead:** ChatGPT (AI Mentor)

---

# 1. Vision

Create a modern Fantasy Premier League analytics platform that helps make better football decisions through data, statistics and artificial intelligence.

The project has two equally important goals:

1. Build a genuinely useful FPL analysis tool.
2. Learn professional software engineering practices by building a real-world application.

The learning journey is considered as important as the finished software.

---

# 2. Mission Statement

Develop a clean, maintainable and well-documented application that demonstrates modern software engineering principles while providing meaningful FPL insights.

Every feature should either:

- improve decision making
- improve user experience
- improve code quality
- improve developer knowledge

---

---

# 4. Project Principles

## Learn First

Understanding is more important than writing code quickly.

---

## Small Steps

Build small working features.

Avoid building large unfinished systems.

---

## Keep It Simple

Choose the simplest solution that works.

Avoid unnecessary complexity.

---

## Document Everything

Every important decision should be written down.

Future Tony should understand every decision.

---

## Continuous Improvement

Leave the project slightly better after every session.

---

## AI is a Team Member

AI assists development.

AI does not replace understanding.

Every piece of generated code should be understood before it is accepted.

---

# 5. Definition of Done

A feature is complete when:

✓ Code works

✓ Tests pass (where appropriate)

✓ Documentation updated

✓ Committed to Git

✓ Code reviewed

✓ Developer understands how it works

---

# 6. Success Criteria

Technical success:

- Stable application

Learning success:
