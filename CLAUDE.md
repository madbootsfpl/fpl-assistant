# FPL Assistant - Claude Code Instructions

## Project Philosophy

This is a learning project.
Prioritise clarity, maintainability and documentation.

## Before Coding

Always:
1. Review relevant documentation
2. Explain proposed changes
3. Identify risks
4. Confirm approach before major changes

## Documentation Rules

Any significant change must update:
- Roadmap
- Journal
- Architecture documents
- Decision records where appropriate

## Coding Standards

- Prefer simple solutions
- Avoid unnecessary frameworks
- Comment why, not what
- Keep modules small
- Write tests for important logic

## Current Architecture

Documentation-first.
AI-assisted development.
Modular design.
